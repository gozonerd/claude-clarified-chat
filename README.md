# Claude Clarified Chat

Un-black-boxes your Claude conversation exports. Drop in a Claude zip export and browse your own conversation history — searchable, readable, and local.

## Where the code is

The application lives in **[`app/`](app/)** — see [`app/README.md`](app/README.md) for install and first-use instructions.

```bash
cd app
npm install
```

## Stack

TypeScript · Vite · Vitest · Playwright (e2e) · Stryker (mutation testing).
