# Claude Clarified Chat

Claude Clarified Chat un-black-boxes your Claude conversation exports. Drop in a Claude zip export and instantly browse your full thread history in a clean, accessible timeline — then export to PDF, DOCX, XLSX, or Markdown. Everything runs locally in your browser; no data leaves your machine. Built to WCAG 2.1 AA accessibility standards and released under the MIT license.

## Install

```bash
npm install
```

## First Use

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser, then drag and drop your Claude zip export onto the landing area.

## Export

Click the **Export** button in the app to download your conversation as:

- PDF
- DOCX
- XLSX
- Markdown
